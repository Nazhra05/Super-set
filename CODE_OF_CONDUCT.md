# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and accept constructive feedback, focus on what is best for the people using these plugins, and do not harass, insult, or attack anyone.

If someone's behaviour in this project's issues or pull requests worries you, report it to the maintainer through GitHub (the maintainer's profile is [Nazhra05](https://github.com/Nazhra05)) or use GitHub's "Report content" option. Reports are handled privately.
